# Desafío Mercado Central de San Salvador

Proyecto académico de la asignatura DMD404.

## Reto 1: Reglas de asociación
Aplicación del algoritmo Apriori para identificar productos que suelen comprarse juntos y analizar las reglas obtenidas.

## Reto 2: Segmentación de comerciantes
Aplicación de K-Means para agrupar comerciantes según sus características y analizar los perfiles de cada grupo.

## Reto 3: Predicción del riesgo de quiebra
Construcción y evaluación de un árbol de decisión para analizar factores asociados al riesgo de quiebra.

## Archivos principales
- desafio_mercado_central.ipynb: notebook con el desarrollo de los tres retos.
- transacciones_mercado.csv: datos de transacciones.
- comerciantes_mercado.csv: datos de comerciantes.
- quiebra_mercado.csv: datos para el análisis de riesgo.
- outputs/: gráficos y resultados.

## Tecnologías
Python, pandas, NumPy, Matplotlib, scikit-learn y otras bibliotecas indicadas en requirements.txt.
